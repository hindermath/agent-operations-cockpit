## Assets, CIA und STRIDE / Assets, CIA and STRIDE

CIA bedeutet Vertraulichkeit, Integrität und Verfügbarkeit. Öffentliche Metadaten haben niedrigen Vertraulichkeitsbedarf; private Rohdiagnosen hohen. Intake-/Receipt-/Review-Bindungen und Autoritätsaussagen benötigen hohe Integrität. Verfügbarkeit ist mittel: ein Ausfall blockiert die Empfehlung, statt einen Lauf zu starten. / *CIA means confidentiality, integrity and availability. Public metadata has low confidentiality needs; private raw diagnostics have high needs. Evidence bindings and authority statements need high integrity. Availability is medium: failure blocks advice rather than starting execution.*

| Bedrohung / Threat | Kontrolle und Beleg / Control and evidence | Restrisiko / Residual risk |
|---|---|---|
| Spoofing: Herkunft wird als aktuelle Autorität gelesen / Provenance mistaken for authority | `receipt_provenance`, `HistoricalOnly`, `NotGrantedByQuery`, `authorityGranted=false`; US3 status/next assertions. | Mensch muss aktuelle Autorität separat prüfen. / Human verifies current authority separately. |
| Tampering: Pfad-/Hash-/Graphmanipulation / Path, hash or graph tampering | `ReadBoundary`, `GuardedPath`, guarded JSON/normalized readers; US2 transitive paths/readers; aktuelle US3 all-Suite; ISG004/007/008/009. | Gleichzeitig ausgetauschte Elternverzeichnisse sind nicht atomar gegen alle Rennen gesichert. / Concurrent parent replacement is not fully race-proof. |
| Repudiation: Ergebnis ohne Herkunft / Untraceable outcome | Quell-/Test-/Loghashes und unmittelbare Exits in US1–US3; genau neun Kriterien in kanonischer Reihenfolge. / Bound hashes, exits and canonical order. | Hash belegt Bytes, keine aktuelle menschliche Zustimmung. / Hash proves bytes, not current consent. |

| Elevation of privilege: Metadaten als Befehl / Metadata as code | Kein eval/Invoke-Expression aus Eingaben; feste lokale Engine, quotierte Argumentarrays; null Folgeprozesse aus dem Kern. / Fixed engine, quoted arguments, no downstream core processes. | Manipulierte installierte Python-Quelle liegt außerhalb der Datengrenze. / Compromised installed code is outside the data boundary. |

Die Lesegrenze validiert jeden transitiven Datenpfad; `O_NOFOLLOW` schützt den letzten geöffneten Eintrag, nicht die ganze Elternkette. Der akzeptierte Scope ist ein lokaler kontrollierter Arbeitsbaum. Bei konkurrierenden fremden Schreibern, Dienstbetrieb oder unbeschränkten Fremddaten muss der Owner vor weiterer Nutzung eine eigene Härtung bewerten. Die Shell darf genau die Validator-Runtime starten; „null Starts“ bedeutet null nachgelagerte Spec-Kit-/Workeraktionen. / *Every nested data path is guarded. O_NOFOLLOW protects the final entry, not the entire parent chain. The accepted scope is a controlled local worktree. Foreign concurrent writers, service use or unbounded external data trigger owner reassessment before use. Shell delegation to Python is permitted; zero starts means zero downstream Spec Kit or worker actions.*
