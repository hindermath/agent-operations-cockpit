Graphlogik, gebundene Quellen und bestehende Agentenbefehle werden wiederverwendet. / *Eligibility means assessed suitability, not permission to start. The feature makes existing series validation explainable and adds missing strict validation of exactly nine criteria. The smallest viable change is an additive local checker with shared Python logic, two thin shell surfaces, focused tests, and required evidence. Reuse graph logic, bound sources, and existing agent commands.*
