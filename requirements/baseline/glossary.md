# Glossargrundlage DE/EN / Bilingual Glossary Baseline

| Deutsch | English | Erklärung / Explanation |
|---|---|---|
| Autorität | authority | Nachweisbare Erlaubnis, bestimmte Daten zu lesen oder Änderungen auszuführen. / Provable permission to read data or make changes. |
| Capability | capability | Abstrakte Fähigkeit wie „Status anzeigen“ oder „Aktion auslösen“, unabhängig vom Gerät. / Device-independent ability. |
| Decision Intake | decision intake | Strukturierte Vorlage für eine noch offene, menschlich zu bestätigende Entscheidung. |
| Degraded Mode | degraded mode | Nutzbarer, aber eingeschränkter Zustand mit sichtbarer Ursache und Grenze. |
| Evidence | evidence | Prüfbarer positiver oder negativer Nachweis zu einer Anforderung. |
| Freshness | freshness | Nachvollziehbares Alter und Aktualitätsniveau eines Zustands. |
| Handoff | handoff | Explizite Übergabe von Daten, Vertrag oder Verantwortung zwischen Owner-Reihen. |
| Lastenheft | requirements intake | Beschreibt Bedarf, Grenzen und messbare Ergebnisse, nicht die technische Umsetzung. |
| Owner-Reihe | owner series | Einzige kanonische Reihe, die einen Concern definiert und ändert. |
| Presentation Fabric | presentation fabric | Gemeinsamer Vertrag für digitale und physische Darstellungsflächen. |
| Projektion | projection | Darstellung derselben kanonischen Zustandsdaten in einem Ausgabeformat. |
| Receipt | receipt | Maschinen- oder menschenlesbarer Ausführungsnachweis mit Scope, Ergebnis und Revision. |
| Recovery | recovery | Geordnete Wiederaufnahme oder Rückkehr in einen sicheren Zustand nach Abbruch. |
| Series | series | Geordnete Menge von Lastenheften mit expliziten Abhängigkeiten und Status. |
| Side Effect | side effect | Beobachtbare Änderung außerhalb einer reinen Abfrage. |
| Snapshot | snapshot | Zeitlich gebundene, unveränderliche Sicht auf erkannten Zustand. |
| Stop-Gate | stop gate | Bedingung, bei der Arbeit nicht automatisch fortgesetzt werden darf. |
| Trust Boundary | trust boundary | Grenze, an der Daten oder Autorität aus einer anderen Vertrauenszone eintreten. |
| Unknown / Stale / Unavailable | unknown / stale / unavailable | Nicht bekannt / nicht ausreichend aktuell / derzeit nicht erreichbar. |
| Vertical Slice | vertical slice | Kleiner durchgängiger Funktionsausschnitt über notwendige Schichten. |
